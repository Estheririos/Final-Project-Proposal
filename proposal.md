# Interactive main menu-Visual Novel

## Repository
<[>](https://github.com/Estheririos/Final-Project-Proposal.git)

## Description
This project will create an interactive main menu for a future visual novel/video game. It creates an interactive art piece that will improve story telling for the visual novel. 

## Features
- Feature 1 color change
	- the display image will change causing the color scheme to change from cute pink to black.
- Feature 2 glitch
	- glitch particles will appear at random intervals in response to the image display changing.
- Feature 3 follow cursor 
	- eyes on the display image will respond to movement of the mouse and follow the movement.

## Challenges
- I need to research what code programs the display image to respond by finding the coordinates of the mouse cursor.
- I need to decide how to get image manipulation.
- I need to figure out how to use the random code to implement my glitches.
 
## Outcomes
Ideal Outcome:
- Ideal outcome would to have a complete main menu for a visual novel that will respond to multiple interactions. This could include changing between two set image displays with glitches in-between, responding to movement of the mouse cursor, changing color schemes when display changes, and responding to a mouse click.

Minimal Viable Outcome:
- Bare essentials would include a display switch between the two images and respond with glitches at the least.
